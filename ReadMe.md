# BMW E38 740d 8HP70 Conversion

This project documents the conversion of a 2001 BMW E38 740d from its original ZF 5HP30 automatic transmission to a BMW F10 ZF 8HP70. It covers the mechanical installation, M67 engine adapter, driveshaft and cooling changes, CANTCU Race+ wiring and programming, and integration of either an F-series gear selector or the original E38 Steptronic selector.

## Requirements

- 2001 BMW E38 740d with the M67B39 engine
- BMW F10 GA8HP70Z-WTT / ZF 8HP70 transmission, mechatronics, and torque converter
- Adamat Performance M67-to-8HP adapter and trigger-flywheel kit
- CANTCU controller with CANformance Race+ software
- Modified and balanced original E38 driveshaft, custom gearbox support adapter, and compatible transmission cooling
- BMW F-series 8HP GWS or a validated original E38 Steptronic selector interface
- Verified transmission identity, installation clearances, wiring, safety interlocks, and conservative calibration
- Qualified fabrication and electrical work, followed by the required legal inspection and approval
